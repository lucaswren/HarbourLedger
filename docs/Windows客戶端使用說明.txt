港賬通 Windows 客戶端

1. 解壓至可寫入的資料夾，雙擊「港賬通.exe」。不要直接在壓縮包內執行。
2. 適用於 Windows amd64，需要 Microsoft Edge WebView2 Runtime，不需要 Go、Node.js、Python 或外部瀏覽器。
3. 設置分為公司資料、備份與恢復、可選功能、資料維護。新帳簿為空白。先在設置填寫公司名稱；公司別名、董事姓名按自己的資料填寫，可留空。
4. 新帳簿須先導入至少一份銀行月結單，再導入採購／銷售發票或收據。預設顯示全部已導入月份。目前銀行解析支援匯豐 Business Direct 文字型 PDF，帳戶幣種為 HKD／USD。
5. 公司名稱和別名用於辨認票據交易方向；未設定公司或資料不確定時，票據保留待核對。董事姓名只有在本帳簿設定後才作識別。唯一候選自動匹配預設關閉，可在設置啟用。
6. 帳簿與原件保存在程式旁的 data。移動整個程式資料夾前請關閉程式；不要單獨複製運行中的 SQLite 檔案。
7. 「設置 → 備份與恢復 → 備份帳簿」生成可恢復 ZIP，包含公司設定、銀行流水、憑證、匹配、覆核歷史、歷史平台核對記錄及董事往來草稿。
8. 點空白首頁或設置中的「恢復備份」，選擇備份 ZIP 並確認。軟件先核驗備份，再在 data/备份 保存目前帳簿；只有全部校驗成功才替換帳簿資料。恢復是替換，不是合併兩家公司的帳務。
9. 備份不包含接口密鑰、程式或視窗快取。OCR 服務區域隨帳簿恢復。密鑰由目前 Windows 使用者的憑據管理員保管。會計師資料匯出 ZIP 不能作為帳簿備份恢復。
10. 備份和資料庫未加密，請存於私人位置。ZIP 大小上限256MB、解壓總量512MB；超出時保留原帳簿並提示。
11. Stripe 餘額摘要從「導入憑證 → 平臺報告 PDF（Stripe 等）」歸檔，可在「記錄與文件 → 憑證文件」預覽，匯出時可選擇附上原件。騰訊 OCR 在設置的「可選功能」。服務區域保存在帳簿，密鑰保存在目前 Windows 使用者的憑據管理員。銀行原件始終本地解析。
12. 流水分類可以自行輸入；收付款關聯及憑證文件在側欄的「記錄與文件」。匯出會計師材料按其實際要求辦理；軟件核對提示不代表會計師的必交材料要求。
13. 同一帳簿重複啟動會返回已有視窗。關閉視窗時等待資料操作結束再退出。啟動問題可查看 data/客戶端.log。

官方 WebView2 Runtime：https://developer.microsoft.com/microsoft-edge/webview2/
