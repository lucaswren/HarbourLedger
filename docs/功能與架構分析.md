# 功能與架構分析

本記錄反映 2026-10-28 的 Windows 通用帳簿版本。

## 定位與架構

單機、單使用者、每個資料目錄一家公司。Go 提供 SQLite 儲存、PDF 解析、憑證匹配與 XLSX/ZIP 匯出；Vue/Element Plus 提供介面；Windows WebView2 提供獨立桌面視窗。本機 HTTP 僅監聽回環地址，桌面版使用動態埠、同帳簿單實例及正常關閉流程。

新帳簿無預設公司、董事或供應商。公司名稱和別名用於票據方向識別；只有設定的董事姓名才作董事往來提示，仍需確認實際款項性質。供應商、客戶及收款帳號從文件或人工輸入取得。自動確認唯一匹配預設關閉。

## 精簡後的模組

保留導入、核查、匯出和備份恢復主流程。設定使用獨立元件和未保存草稿；公司資訊、備份、可選服務、維護操作分頁展示。騰訊 OCR 設定按需載入，無董事交易時不顯示董事面板。

移除舊版資料目錄遷移、外部核驗JSON覆蓋、重複初始化命令及歷史專案清理腳本。既有帳簿的必要結構升級、覆核保護和備份恢復仍保留。原本依賴私有資料的匯入、重建和匯出測試改用程式產生的虛構PDF，可獨立執行。

## 帳務邊界

銀行收入／支出按幣種分列，不直接等同收入／費用。內部轉帳、董事往來、平台淨結算分別核對。原幣未列示時不反推金額；發票、銀行實扣與分配金額分別保留。確認分配時檢查幣種、超額、覆核人及憑證有效性；修改歷史和結帳鎖定由 SQLite 控制。

會計師材料需求與軟件內部核對提示分開。平台交易明細只有在實際需要時才整理，不作預設必交材料。軟件不代替總賬、試算平衡、應計與稅務處理。

## 備份恢復

備份由 SQLite `VACUUM INTO` 一致性快照及按 SHA256 核驗的原始 PDF 組成，包含公司設定、匹配、覆核歷史、平台資料和董事草稿。接口密鑰留在本機 `.env`。

恢復流程：ZIP 大小及路徑檢查 → SQLite 完整性、必要欄位及業務 JSON 檢查 → 原件 SHA256 核驗 → 備份目前帳簿 → 寫入獨立原件目錄 → 同一交易替換所有業務資料及恢復覆核保護。資料庫使用本程式的表結構和觸發器，不執行備份來源的觸發器。拒絕 ZIP 路徑越界、符號連結、重複名稱及缺失／損壞原件。ZIP 上限256MB，解壓總量上限512MB，最多5000個項目。

恢復後資料庫和設定回到備份時點；密鑰、已有匯出文件及未引用的舊原件不被刪除。恢復前備份保留在 `data/备份`。Windows 客戶端關閉前會等待正在處理的資料操作。

## 通用性及尚未支援的範圍

| 項目 | 狀態 |
|---|---|
| 公司、董事、客戶及供應商 | 無固定企業資料；按帳簿設定和文件內容 |
| 行業 | 使用一般採購／銷售／服務描述；沒有庫存、工資或生產模組 |
| 銀行 | 目前僅匯豐 Business Direct 文字PDF解析器；需新增其他銀行適配器 |
| 幣種 | 現有帳戶、解析和部分報表限HKD／USD；不能宣稱任意幣種支援 |
| 會計制度 | 憑證整理與收付款匹配；非完整複式會計或跨地區稅務系統 |
| 使用方式 | Windows amd64單機；多人、權限分工、安裝升級和程式簽章未實現 |
| 資料儲存 | 本地SQLite和PDF；未加密，備份持有人可讀取帳務 |

## 開源發布條件

公司帳簿、原件、歷史工作資料與接口密鑰保存在私有目錄。公開候選來源包只包含明確列出的程式、虛構測試及使用文件，不包含私有目錄、舊版程式、資料庫或憑證。

主項目採用 Apache-2.0。已保留本地 PDF 修補的 BSD 許可、字寬資料的 MIT 許可、字型的 OFL 文本及依賴許可收集流程。視窗錢包圖示的來源和 MIT 許可見根目錄 NOTICE。執行桌面版需要 Microsoft Edge WebView2 Runtime。
