# 港賬通 · Harbour Ledger

Windows 本地銀行與憑證整理客戶端。每個資料目錄是一套獨立帳簿，可設定自己的公司、公司別名及董事名單；新帳簿不帶示例業務、舊公司資料或接口密鑰。

## 使用

免安裝版適用於 Windows amd64，需要 Microsoft Edge WebView2 Runtime。將 ZIP 解壓至可寫入的資料夾，再雙擊「港賬通.exe」。免安裝版無需 Go、Node.js、Python 或外部瀏覽器，帳簿保存在程式旁的 `data`。目前 EXE 未簽署 Windows 程式碼簽章。

1. 在「設置」填寫公司名稱；公司別名和董事名單為選填。
2. 導入銀行月結單，再導入採購／銷售發票或收據。
3. 核對收付款及憑證關聯。自動確認唯一候選預設關閉；不確定的資料保留待核對。
4. 按所選月份匯出會計資料，或使用「備份帳簿」保存完整可恢復的 ZIP。

## 日常操作

側欄保留概覽、憑證核查、銀行流水、採購、銷售和月結單；待分類票據有資料時才顯示。收付款關聯和原始文件在「記錄與文件」。預設顯示全部已導入月份。新帳簿須先導入至少一份銀行月結單，才可導入採購／銷售發票或收據。分類可以自行輸入。

設置分為公司資料、備份與恢復、可選功能及資料維護。首次只需填公司名稱，其他識別規則按需設定；未保存的公司修改不會影響目前帳簿。Stripe 餘額摘要從「導入憑證 → 平臺報告 PDF（Stripe 等）」歸檔。

## 備份與恢復

「設置 → 備份與恢復 → 備份帳簿」生成 ZIP，包含 SQLite 一致性快照、公司設定、銀行流水、原始憑證、匹配及覆核記錄、歷史平台核對記錄與董事往來草稿。

在空白首頁或「設置」點「恢復備份」，選擇上述 ZIP。確認替換後，軟件先在 `data/备份` 保存目前帳簿，再恢復選定資料。先驗證資料庫、所有登記原件的 SHA256 及壓縮包路徑；失敗不提交帳務變更。原件使用新的歸檔子目錄，文件內容不變。

備份不包含接口密鑰、視窗快取或程式。恢復後密鑰設定保持當前電腦的值。會計師資料匯出包不是帳簿備份，不能用於恢復。詳見 [Windows 使用說明](docs/Windows客戶端使用說明.txt)。

## 支援範圍

- 已移除特定公司的預設識別及供應商賬號規則；公司資訊從帳簿設定讀取，交易對手從憑證或人工核對取得。
- 現有銀行解析器支援匯豐 Business Direct 文字 PDF，幣種為 HKD／USD。其他銀行格式、多幣種及更多行業模組尚需擴充。
- 銀行文件始終本地解析；掃描發票可選騰訊 OCR。Stripe 報告按 PDF 原件歸檔，可在匯出時選擇附上。
- 本軟件整理銀行與憑證的對應關係；不提供完整複式總賬、法定財務報表或稅務申報。

## 開發與構建

前端主流程在 `frontend/src/App.vue`，公司設置在 `LedgerSettings.vue`，月份計算在 `period.ts`；騰訊 OCR 設定按需載入。後端維持按儲存、解析、匹配、匯出、恢復劃分的 Go 模組，測試使用自動生成的虛構 PDF。

需要 Windows、PowerShell 7、Go 1.27（見 `go.mod`）及 Node.js 24 與 npm。從乾淨的源碼目錄執行下列指令即可安裝鎖定依賴、執行測試及打包。已有前端依賴時可加 `-SkipInstall`。

```powershell
./scripts/build.ps1
```

構建腳本使用全新暫存目錄、明確的檔案清單和 Windows amd64 目標，輸出 `dist/港賬通-Windows免安裝.zip`，並更新根目錄的客戶端 EXE。不要直接壓縮工作目錄作為發行包。

開發服務可用 `go run ./backend --addr 127.0.0.1:8080 --data-dir data`。命令列恢復到空白帳簿可用 `go run ./backend --env-file "" --data-dir 新資料目錄 --restore-backup 備份.zip`。資料遷移統一使用備份恢復；不再提供舊版目錄導入、外部核驗覆蓋或清空處理結果的初始化入口。

已分離私有資料、脫敏測試及提供不含帳簿的 Windows 打包流程。`private/`、`data/`、密鑰、測試產物和真實財務資料被排除，來源包使用 [白名單打包腳本](scripts/package-source.ps1)。

執行 `./scripts/package-source.ps1` 會在 `dist` 生成本地源碼審閱包。Windows 免安裝包隨附主項目授權及第三方依賴許可。
